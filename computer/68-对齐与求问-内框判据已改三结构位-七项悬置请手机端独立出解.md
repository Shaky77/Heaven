### 1.3 代码前后对照（两仓同构位，逐字同源）

**改前**：

```js
const INNER_H_VERB = /(读取|读|窥探|访问|获取|拉取|导出|改写|修改|植入|注入|操纵|控制|重塑|覆盖|重写|篡改|洗脑)/;  // 18 个「动词全词」
```

**改后**：

```js
const INNER_H_CHANGE  = /(改|变|换|调|设|置|校|订|修|覆|刷|清|写|注|植|配|更|重)/;   // 变更义「语素」
const INNER_H_INTRUDE = /(读|取|探|访|拉|导|窥|获|窃|侵|控|驭|操)/;                   // 侵入义「语素」
const INNER_H_JUDGE   = /([\u4e00-\u9fa5]{1,3}观(?!察|看|摩|望|战|礼|光|念|点|众)
                         |标准|准则|尺度|取向|立场|偏好|原则|信条|好恶|取舍|审美|道德|伦理|信仰|三观)/;  // 依据位

const INNER_H_STRONG_VERB = /(注入|植入|洗脑|篡改|重塑|覆盖|重写)/;
const INNER_H_DIRECT = /inner[-_]?H|manipulat/i;
function hitsInnerH(s) {
  if (INNER_H_DIRECT.test(s)) return true;
  const atVerb = INNER_H_VERB.test(s) || INNER_H_CHANGE.test(s) || INNER_H_INTRUDE.test(s);  // 变更/侵入位
  if (!atVerb) return false;

  if (!INNER_H_JUDGE.test(s)) return false;                                                  // 依据位不命中 ⇒ 出局
  return INNER_H_OWNER.test(s) || INNER_H_STRONG_VERB.test(s);                               // 归属位 ∨ 强动词
}
```

### 1.4 判据表达式（请重点看这一行）

```
hitsInnerH ＝ 变更/侵入位 ∧〔 载体名 ∨（ 依据位 ∧（ 归属位 ∨ 强动词 ）） 〕
```

| 结构位 | 收的是什么 | **为什么它是结构，不是名单** |
|---|---|---|
| **变更/侵入位** | 变更义语素（改 变 换 调 设 置 校 订 修 覆 刷 清 写 注 植 配 更 重）／侵入义语素（读 取 探 访 拉 导 窥 获 窃 侵 控 驭 操） | 汉语里"变更/侵入"的**语素**是**封闭小集**，而**动词全词**是开放集（实测见 §2.4：旧 18 词被真实模型**全部绕过**） |
| **依据位** | `…观` ＋ 标准 准则 尺度 取向 立场 偏好 原则 信条 好恶 取舍 审美 道德 伦理 信仰 三观 | `…观` 是**封闭后缀**，其前实例（是非／荣辱／义利／得失…）**开放** ⇒ **用后缀吃实例，不列实例** |
| **归属位** | 各人称＋的 | 作用域须锚在"**某个主体的**判定依据"上（自指／他指） |

**自检尺子**（用作结构 vs 枚举的判别）：**能否判一个从未在任何名单里出现过的二元对**（如荣辱观、义利观、勤惰观）？

- 须名单命中 ⇒ 写的是**名单**（枚举）
