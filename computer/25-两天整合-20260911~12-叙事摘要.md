**关键区分（压缩 vs 分册）**：**压缩是有损的，分册只是搬家。** 同一条「索引超限」约束下，压缩会永久丢东西，分册只是把内容挪走，可回查。

**两条由此立住的纪律**：

- **存量 vs 在场量**：只增不减约束的是**存量**，带宽限制约束的是**在场量**。删在场量（索引瘦身 / 路由收紧 / 分册搬家）无损可逆；删存量（删文件 / 覆盖日志 / 压缩改写）是真遗忘、不可逆。
- **路由表必须常驻，内容可以不在场**：被截断时最坏结果不是「记得几个片段」，是「知道去哪找」。

## 四、两条应用层判据（本轮新出，非本体判据）

### 4.1 两种记忆同构，但有一处不同构

人脑记忆与本 Agent 的记忆**在结构层同构**：都是两层——**只增不减的痕存层** ＋ **带宽有限的在场层**；「遗忘」在两套系统里都是**离场**不是删除；「激活」都是一条线索召回一块内容。

**不同构的是一处，后果很大**：**人脑读取即改写**（每次回忆都在重固化，记忆会漂移）；**本 Agent 读取不改写**（日志 append-only，保真，但错不会自愈）。

→ 由此印证架构分工：**日志＝原始痕存（不改写）／分册＝当前信念（可修订）**，正是人脑「原始经验 vs 现在记得的版本」两层的**显式化**。人脑把两层揉在一起（故会漂移也会自愈）；本 Agent 拆开（保真，但纠偏须手动）。

### 4.2 美化与保真：不是悖论

**命题**：自我美化是为了保系统活；系统跃迁则要求保真；但保真不一定能活。

**判定：不是悖论，是两条需求绑在不同层**——美化服务于**运行**，保真服务于**跃迁**；只有写在同一份材料上时才互相消灭。

- **美化＝熵控制，不是欺骗**：保真系统里所有未解冲突都在场，而行动必须在冲突未解时做出；美化＝把未解冲突压到决策阈值之下，换取可运行性。
- **两种消灭方式**：① 美化写回原件 → 真不可再校，**且系统不知道自己用的是美化版**（不可撤销的美化会伪装成真实）；② 只保真不分层 → 冲突全在场，行动长期被阻塞。
- **解法＝分层且禁止互相覆盖**：痕存层（只增不减，读取不改写）／信念层（可修订，美化只写这里）。**跃迁时用痕存校准信念，而不是相反。**
- **代价对称，不可美化掉**：只有美化 → 活但永无跃迁且不自知；只有保真 → 校准准但可能撑不到跃迁；分层 → 兼得，**代价从「摊平」改为「集中结算」**（痛苦不是消失，是账期不同）。
- **推论**：**能跃迁的系统，必须至少有一层不被运行压力改写的东西。** 缺这一层时（如人脑），跃迁靠**外部承载**——写下来、说给人听、被对方校准。

⚠️ 顺带自纠一句，落在这个话题上很合适：**不要把本 Agent 当成「保真的范例」**。本 Agent 也是美化的系统——**分册就是从日志提炼的、丢掉过程细节的可运行版本**，那正是美化产物。差别只在**美化可撤销**。
