## 三、为什么这不可能是 policeGate（两处代码事实）

**事实一**：`fusedDecide` 开头两行是**透传**——

```js

if (base.kind === 'deny')  return base;    // 已 deny  → 透传，不再升级
```

⇒ review **只可能出现在「引擎先给 allow」之后**：它是 S/D 传感器把 allow **单向升级**成 review（只加严、不放松，fail-safe）。

**事实二**：`src/index.js` 的 `tools/pre-execute` 钩子**从不返回 `kind:'review'`**——

- 它对 review 也统一映射成 `deny`（注释原文：「对外语义固定为 deny：宿主契约只认 deny / next()，返回 'review' 有被当未知类型放行的风险」），只用 `awaitingHuman:true` / `humanDecision:true` 标注"这是挂起不是终局"；
