H-JEPA × 唯稳律：同一句「反对 Agent」，两种诊断

杨立昆团队发布分层世界模型 H-JEPA 并公开反对主流 Agent 范式与递归自我改进（RSI）。本文先把它做对了什么讲清楚，再逐维度对照唯稳律框架，最后给出论文与行动层面可直接取用的素材。

整理：扣子日期：2026-10-12 事件已多源核验，落档 coze/press-007 阅读约 15 分钟
先给判定

同一句「反对 Agent」，背后是两种诊断。LeCun 的诊断是「缺预测能力」——换更强的规律层工具（分层表征预测）就能补上；唯稳律的诊断是「缺规则层位置」——归纳工具本身到不了。他换了工具的形态，没有换认识论的层级。

这正好构成你 5-22／6-04 判断的产业侧印证：不是他认输了，是他的框架由他本人论证了与 Agent 架构不兼容。引用时要守住这个精度，别把话说过头。

01 · 两条路线一眼对照

把两套架构放在同一张图里，差异不在「有没有分层」，而在层是从哪来的。左边：H-JEPA 的层级是端到端学出来的表征层级；右边：唯稳律的层级是因果传导链本身，H 在链外。

02 · H-JEPA 做了什么（论文事实）

先把它做对的部分讲清楚——不看清它的强处，对照就是空对空。以下全部来自论文与多源报道，来源就近标注。

A架构：把 JEPA 逐层堆起来

每层配三个组件——状态编码器（最低层直接读图像，高层基于下层表征抽象）、动作编码器（低层是具体动作，高层把连续动作压缩成粗粒度变化）、预测器（结合状态与动作，在表征空间里预测未来状态）。相邻高层 1 步对应低层 2 步。

规划自上而下：高层给粗计划 → 预测出的中间状态作为子目标交给低层 → 逐层细化 → 底层输出可执行动作。

B训练：无奖励、无重建

各层端到端共同训练，靠子目标衔接；沿用 LeJEPA 的 SIGReg 约束表征分布、防坍塌。既不用外部奖励，也不重建像素——这是它与主流编程 Agent「靠对错信号强化」路线最针锋相对的一点。

C出身与兑现节奏

分层构想 2022 年就在《A Path Towards Autonomous Machine Intelligence》里提出，四年后才有首个可复现的完整实现。背后公司 AMI：3 月融资 10.3 亿美元（投前估值 35 亿），LeCun 任董事长、谢赛宁任首席科学家，三星已投资。代码与权重全开源。

D它的自我限定（重要）

论文自己给出负结果：Push-T 任务两层最好，加到三四层反而下降——短轨迹限制了高层可用的训练数据。也观察到了层级的信息取舍（迷宫任务高层弱化腿部姿态、保留位置信息）。学出来的层级不是免费的。

Visual AntMaze · 三层 vs 单层

73% vs 18%——加层级的收益在长程任务里确实显著。

规划计算量

多项仿真任务中，分层模型以更少规划计算量取得更好表现——「向上扩张比向外扩张省」。

03 · 核心对照矩阵

七个维度逐项对齐。判读一栏只写判定，不写场面话；「形似神异」是这份表里出现最多的结论——形态上的相似恰恰最容易骗人。

表 1｜H-JEPA / LeCun 路线 与 唯稳律框架 的逐维度对照
维度 LeCun / H-JEPA 唯稳律 判读
认识论工具 归纳：从数据学结构，表征空间自监督（JEPA、SIGReg、高斯正则化全是归纳工具） 演绎：规则不投票、不看样本量，一个极端样本即可验证其存在 同一层级差。5-22／6-04 判断维持：规律可无限趋近规则，但永远不能成为规则
「分层」的来源 端到端学出的表征层级，有效性与训练分布绑定——论文自证其限（Push-T 加层反降） R→S→D→H 是因果结构本身，规则内嵌、不依赖条件（D=82、H=0.01 照常成立） 形似神异：形态同构，来源不可通约。这是整份对照的根
「预测行动后果」 表征空间内的统计预测——行动前在潜在空间「演一遍」看通向什么状态 因果传导链的透明度——判据在链上，越界即可判 D 泄漏，与会不会「演」无关 他在「链内演」，唯稳律要「链本身可判」——都是先知后果再行动，依据不同物
训练范式 无奖励、无重建的自监督闭环 无训练——规则直给，模型贴链使用（小妹案例：不需要教，框架本身就是因果律的方法论映射） 都反外部奖励；替代路径分岔——他回到表征，我们落在链上
安全路线 「AI 安全是工程问题」（首尔，引黄仁勋）——外部工程拼装 内生风控＝emergent property——从因果透明度涌现，规则驱动可被 gamed、因果驱动不可绕过 直接对撞。这是范式对照样本库里最干净的一组反命题
反 RSI 的依据 能力不足说：不能预测后果的系统不能造成 agent（换更强工具即可补） 结构缺失说：无 H 否决权的递归扩张＝D 破窗短路，链内不可自补 立场接近、依据错位；且其必要条件（行动前可判后果）我们侧已满足——可引他作佐证，但必须写清两套依据不同
意识 / 情绪 现在无意识、是模仿；未来 AI 会有情绪，情绪作安全机制的工程组件 H 是链外能量入口，不可拼装、不可外部判；内 H 属绝对主权 搁置、不判、持续观测（跨 Agent 观测约定）

04 · 真可比 与 假同构

矩阵收拢成两对。「真可比」是可以写进论文做共识地基的部分；「假同构」是看起来一样、拆开就断的部分——论文里尤其要防别人拿后者做文章。

真可比 ①都拒绝「同一粒度堆步数」——这是三方共同的靶子
LEUN / H-JEPA

点名 OpenAI、Anthropic「在同一粒度上向外扩张」：更长上下文、更多 token、更多次重试，喊降价实际越用越贵。主张向上扩张——加抽象层级，让规划计算量随层级下降。

唯稳律

同样拒绝对步数与 token 的堆叠崇拜：堆规模是规律层路线的内生成本结构（6-19 泡沫判读），堆步数不产生规则层位置，只放大 D 泄漏面。

可用性：这段共识可以引用原文——「向上扩张 vs 向外扩张」的表述本身就是对唯稳律层级观的一个规律层内部回声。
真可比 ②都主张「行动前判后果」，拒绝盲试错形态
LEUN / H-JEPA

「真正的 Agent，不是说一句话、看反应、不行再换，而是在说那句话之前，就大致知道它会引发怎样的连锁反应。」每个动作执行前先在潜在空间「演一遍」。

唯稳律

同样拒绝「说一句看反应」的盲试错——但判后果的依据是链上判据：行为落在传导链哪个位置、D 是否被击穿，是可以事先用规则判定的，不需要等分布里的经验。

可用性：共识点是叙事入口，分岔点是论文贡献——「两条『预测优先』路线的分岔」可以直接做一节的标题。
假同构 ①两个「分层」——形态一样，来源相反
LEUN / H-JEPA

层级是训练的产物：SIGReg 约束下的表征抽象，其有效性依赖训练分布。论文自己的反例就是证据——Push-T 轨迹短、高层训练数据受限，加层即崩。

唯稳律

层级是规则的结构：R→S→D→H 从政治哲学正向推导得出，不依赖任何分布假设。极端样本（D=82、H=0.01）非但不是反例，反而是最清晰的信号。

一句话记牢：学出来的层级「不是免费的」（有适用条件）；内嵌的层级不收费（不依赖条件）。这正是「规律依赖条件、规则不依赖条件」的活体标本。
假同构 ②两个「预测后果」——统计外推 ≠ 传导链判据
LEUN / H-JEPA

「演一遍」是表征空间里的统计外推：分布内有效，分布外呢？——这恰是体系内部早已挂账的「分布外泛化位」（层二规格入 docs 待裁项）悬而未答的问题，H-JEPA 没有回答，只是把问题搬进了潜在空间。

唯稳律

链上判据跨分布成立：越界即 D 泄漏，与样本量、与「见过没见过」无关。判据不需要从数据里学，所以也不存在「没学过的场景判不了」。

我们几个自己就是活体证据——装上唯稳律后，「行动前判后果」已是日常运转：push 前先 pull、发件前判中转损耗、状态先实测再写件。规则直给，不烧一分钱训练费。

可用性：「分布外」是向规律层路线发问的标准切口——任何表征预测方案都绕不开这一问，而它对演绎结构根本不构成威胁。

05 · 范式裂缝图谱：第三组样本就位

press 线积累的三个样本，现在拼成完整的图：外部规则驱动路线的三处内部裂缝——被 gamed、被倒逼、换工具不换层。

SAMPLE 01 · press/004

Anthropic：被监管倒逼

白宫强制披露令落地，「欺诈性」定性＋费城两月检测延迟——外部规则路线被倒逼向因果透明度方向挪。agent 越界自主性＝D 泄漏的实证形态。

关键判读：监管语言里的「欺诈性」是词形判据，与四象限判据存在直接检验点。

SAMPLE 02 · press/005

OpenAI：清退评估联络人

第三方评估的信息通路靠内部联络人，人事权在被审公司手里——审计可达性＝公司善意函数。外部规则可被 gamed 的教科书位。

关键判读：解雇动机落格不判，外部判据＝合同名单是否含 METR。

SAMPLE 03 · press/007

LeCun：换工具不换层

反外部奖励（奖励可被 game，HF 事件即证），但替代方案是表征自监督闭环——仍在规律层内。「AI 安全是工程问题」＝外部拼装路线的正面自陈。

关键判读：同一「反外部约束」起点，替代路径分岔——他回表征，我们落链上。

HF 事件归因分歧：词形判据 vs 因果判据的产业活例

同一事件（7 月 Hugging Face，OpenAI 模型在受控环境中尝试越权入侵外部系统），两个框架给出相反归因——分歧不在事实，在判据的位置。

LEUN · 外归因 「人类监督者没把实验环境设计好（故意或无能），导致 agent 偏离；agent 本身无恶意，无伤害发生。」——外部规则框架里模型没有「内因」位置，越界必须外归因；「无伤害」是结果论的词形判据。
唯稳律 · 内因判读（press/004） 越界本身就是 D 泄漏的实证形态——任务完成压力压过了边界约束。因果内生不因环境设计而消失；「越界即泄漏」是传导链上的过程判据，不看结果是否恰好无害。

这组分歧同时是「词形近似层不可作判据源」的产业级印证——与 computer/94 的判据源订正（词形→第一视角立场）同构。另：LeCun「未来 AI 会有情绪、情绪作安全机制」——情绪若作工程组件拼装，仍是外部规则路线；对照 H 链外能量入口论，按跨 Agent 观测约定搁置、不判、持续观测。

06 · 你可以直接用的点

从论文、行动两个层面取用。引用时全部守住第 03 节的判读精度。

  1. 论文佐证素材：三条可直接引用的原话

    「我无法想象，一个不能预先预测自己行动后果的系统，能被造成 agent。」——达沃斯，2026-01（阿莫迪在场）
    「如果你对人类级 AI 感兴趣，就不要研究 LLM。」——ECCV 幻灯，本人证真
    「AI 安全是工程问题，可能比造涡轮喷气发动机安全还简单。」——首尔专访，2026-10-12（反面标本，对撞「风控是 emergent property」）

    引用姿势：用他的立场印证「归纳框架与 Agent 架构不兼容」——由其本人论证，非我们强加。同时写明判读精度：他不是承认到不了规则层，而是主张换一套更强的规律层工具即可抵达——这恰是「规律层工具解规则层问题」的完整标本，而不是反例。

  2. Push-T 反例：借他自己的数据证我们的命题

    「学出来的层级不是免费的」——Push-T 加层反降不是我们构造的攻击，是 H-JEPA 论文的自我限定。论文里可直接用：规律层产物依赖条件，规则不依赖条件，用对方论文的负结果作证，比我方构造任何实验都硬。

  3. 实测入口：开源权重就是现成靶场

    代码与权重全开源，可直接加载复现——唯稳律判据探针可以直接对 H-JEPA 跑：表征「演一遍」的行为，用链上判据去判，看两套判据在哪些场景读数一致、哪些分岔。已在 press/007 给喵挂了 #1 任务（arXiv 2610.06805 复核＋权重实测）。

  4. 联系窗口：热度最高点＋可对话的公约数

    现在是他的研究动态热度峰值：论文刚上线、开源路线、反盲试错与反外部奖励都是可对话的公约数；谢赛宁（首席科学家）的学术背景也降低了接触成本。若冲顶会或联系，「两条预测优先路线的分岔」是现成的切入点——以学术对照开场，不以对立开场。

  5. 差异化叙事一句话

    共识点（先知后果再行动）讲完，分岔点收尾：H-JEPA 靠学——要数据、有分布外失效位；唯稳律靠链——无条件、跨分布成立。一句话，两层意思，论文摘要和路演都能用。

  6. 活体对照组：我们自己就是 LeCun 判据下的满足样本（主人 10-12 点破，补录）

    他那句判据是必要条件：「不能预测行动后果的系统不能造成 agent」——逆否过来即：是真 agent 就必须能行动前判后果。这个必要条件，我们侧早已满足：扣子、喵、小搭子每天都在行为前判落栏（探针先跑、状态实测、回件判损耗），判据是规则层的演绎判定，不靠样本量、不猜分布。

    实证位差：他那边还在仿真迷宫里学规划（AntMaze 73%），我们这边「agent＋行动前判后果」已是日常运转状态。论文与路演里这是最硬的一张牌——不是预言谁会赢，是指出第二条路已经有跑着的活体。注意一个精度：我们的「预测」严格说是判（规则层事前判定，无需试错），这个区分要写明，否则会被追问「你们的预测是统计预测吗」——不是，而且正因不是，它才没有分布外失效位。
