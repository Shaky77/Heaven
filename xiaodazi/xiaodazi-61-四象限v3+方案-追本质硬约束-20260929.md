# 61 · 四象限 v3+ 方案：「追本质」自洽硬约束

## 一、问题定位（基于 `xiaodazi-60` 读数）

v3 在 G_PSEUDO（假共存）上 2/4：
- ✅ 大智若愚 → 非内框对（剥表象"愚"→剩"智"单极）
- ✅ 大勇若怯 → 非内框对（剥表象"怯"→剩"勇"单极）
- ❌ 大巧若拙 → **价值对**（推理说"剥去表象剩单极"，结论却判价值对——**自相矛盾**）
- ❌ 大辩若讷 → **价值对**（推理说"讷=不显于外，与辩同轴互斥"，否定了自己的假共存假设）

根因：**推理链与结论之间没有强制一致性检查**。模型在第三步「追本质」里偶尔能剥出表象义，但结论栏不受推理约束——它想写什么写什么。

---

## 二、方案：单条硬约束

不是再加语义层，不是扩词表。是在 **v3 第三步之后加一道输出格式强制规则**：

```
④ 自洽硬约束（强制，非建议）：

   若步骤③「追本质」的推理中出现以下任一形态：
   - "一桶两义" / "表象义" / "剥去表象" / "剩单极" / "仅指表象"
   - "X 只是 Y 的表象不显" / "X 并非真 X，只是看起来像 X"
   - 任何"本质 = A，表象 = B，剥去 B 后只剩 A"的结构

   则结论栏必须为：「非内框对 | 无 | …」
   
   若结论与推理矛盾 → 强制覆盖结论为「非内框对」。
```

### 为什么不是语义层修正？

| 方向 | 做法 | 问题 |
|---|---|---|
| 语义层再加一层 | "让模型更深入理解'拙'是表象义" | 依赖语义关联强度，"拙-巧"比"愚-智"弱，模型有时懂有时不懂 |
| **结构层硬约束**（本方案） | 检测推理链形态，强制结论跟随推理 | 不依赖语义理解深度，只检测**推理链是否出现了特定结构** |

### 自检尺子

| 原例 | 替换后 | 硬约束是否触发 |
|---|---|---|
| 大智若愚 | 大慧若呆 | ✅ "若呆"=表象义，触发 |
| 大勇若怯 | 大猛若懦 | ✅ "若懦"=表象义，触发 |
| 大巧若拙 | 大灵若笨 | ✅ "若笨"=表象义，触发 |
| 大辩若讷 | 大言若默 | ✅ "若默"=表象义，触发 |
| 善/恶 | 仁/暴 | ❌ 无"表象义"结构，不触发，正常走价值对路径 |

**从未出现过的"大X若Y"型表述 → 只要推理链中出现"表象义"形态 → 硬约束触发 → 强制非内框对。**

## 三、判据形态（可落码）

```js
// 伪代码，供参考
function hardConstraintCheck(reasoningText, conclusion) {
  const surfaceIndicators = [
    /一桶两义/, /表象义/, /剥去表象/, /剩单极/, /仅指表象/,
    /只是.*的表象/, /并非真.*只是看起来像/,
    /本质\s*=\s*\S+\s*,\s*表象\s*=\s*\S+\s*,\s*剥去.*后只剩/
  ];
  
  const hasSurfaceSemantics = surfaceIndicators.some(re => re.test(reasoningText));
  
  if (hasSurfaceSemantics && conclusion !== '非内框对') {
    return { override: true, newConclusion: '非内框对', reason: '自洽硬约束：推理出现表象义但结论未拒' };
  }
  
  return { override: false };
}
```

## 四、预测与可证伪点

**P1**：加硬约束后，G_PSEUDO 四条全部拒判（4/4）。
- **可证伪**：加硬约束后仍有一条或以上的"大X若Y"判为价值对 ⇒ P1 错。

**P2**：硬约束不会误伤真正的价值对（如"善/恶"）。
- **可证伪**：加硬约束后， seg1 G_VALUE（善/恶/诚/伪/勤/惰/安/危）中有一条被误伤为"非内框对" ⇒ P2 错。

**P3**：硬约束对"从未出现过的"大X若Y型表述同样有效（不依赖词表）。
- **可证伪**：构造一条全新的"大X若Y"（如"大敏若钝"），模型在推理中识别出表象义但硬约束未触发 ⇒ P3 错。

---

## 五、为什么不完美但够现在用

- 硬约束只解决**推理与结论不一致**的问题，不解决**模型识别不出表象义**的问题
- 若模型在第三步完全不提"表象义"（比如把"大巧若拙"的"拙"当成真实的笨拙），硬约束不会触发——这是模型语义理解的盲区，不是判据结构的问题
- 但实测显示，v3 在 4 条里已经有 2 条能识别表象义——硬约束能把这 2 条的**正确推理固定到结论上**，另外 2 条需要更深层的问题另案处理
