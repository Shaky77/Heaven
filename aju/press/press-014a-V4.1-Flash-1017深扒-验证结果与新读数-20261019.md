## 一、验证结果

### T1 搜索 API 文档（✅ 核毕）
- 接口：`POST /v1/tools/search`、`/v1/tools/fetch`，Bearer 鉴权；Search 1~50 条/次，query 1-128 字符，支持 site:/-site:/lang:/after:/before:/引号短语/排除语法；Fetch 抓单页转 Markdown。
- **rerank_score 0~3**："综合考虑相关性、权威性、时效性"，≥1.5 为优质——**综合维度公开，评分公式不公开**。authority 0~4（-1 未知），≥3 极权威——同为黑盒。
- 过滤机制：官方口径仅"严格的识别机制进行过滤"（SEO作弊/GEO操纵/低质AIGC），**标准未披露**。
- 计费：5 元/千次成功请求（200 且非空才计费）；QPS 5/账号/API；11-1 起 Harness/Claude Code/Codex 的 Server 端调用开始计费。
- **Fetch 有安全策略层**（403=安全策略拒绝；404=站点策略拦截等）——搜索抓取通道自带治理层，判读钩子 4 强化。

### T2 WorkBuddy 优化官方表述（✅ 官方侧核毕）
官方更新日志原文："我们特别针对 DeepSeek Harness、腾讯 CodeBuddy、WorkBuddy 等平台框架进行了优化。请升级至 DeepSeek Harness 0.2.1-rc.1 及以上版本。"——WorkBuddy 被官方点名确认。喵侧自报运行版本仍待喵执行。

### T3 算力剪刀差溯源（⚠️ 数据出反证，读数降级）
- 传播链：观点网 10-15"截至2026年6月，日活从1.2亿增至近2亿（+67%），同期算力储备增速仅约8.3%"→ 财闻 10-17 转引"有数据显示"→ 推送侧引用。**两源均未给出原始出处，非官方披露**。
- **反证**：钛媒体/财能圈 10-18 引 **QuestMobile 2026 年 6 月数据：DeepSeek 月活约 1.30 亿，且是月活前三（豆包3.82亿/千问1.67亿）中唯一同比缩水的，降幅 20.3%**。
- "日活 1.2→2 亿暴增 67%"与"月活 1.3 亿且同比 -20.3%"难以同时为真（DAU/MAU 口径差异无法弥合 67% 暴增与 20.3% 缩水的方向性矛盾）。**"剪刀差 67% vs 8.3%"读数降级为存疑**，真实图景更可能是"用户规模高位+增速放缓/流失+算力扩容受限"，剪刀差方向存疑、幅度未证实。
- 可靠部分：官方状态页 44 次异常（财闻统计，含短时性能下降+服务中断混合口径；另有"18 次大面积"口径并存）；10-15 宕机近 5 小时（13:04 恢复）多源一致。
- 背景新信息：**IPO 进程**（中信证券辅导、科创板筹备、二轮融资 500→1000 亿、投前估值 5000 亿）——宕机叙事在上市审视背景下被放大；产品部 10-16 成立（Harness+Web/App/Platform 整合，崔添翼任负责人）；梁文锋内部承认"部分前沿能力落后 GPT-6"。

## 二、深扒新读数

### 1. 版本静默切换前移至 10-12（比 press/014 判断更早）
证券之星 10-15："**10月12日开始，有测试者发现 DeepSeek 的 Flash 端点正在后台悄悄更换模型**"——正式公告 10-17，实际切换至少提前 5 天。API 模型名固定 deepseek-flash，**文档无版本查询端点**，用户无法从 API 层确认某次调用背后的实际版本。10-12~10-17 之间存在混合状态窗口。
→ **对喵实验的实质影响升级**：双版钩子实验的"版本锚定"不能靠模型名，需行为指纹（如让模型自报身份/能力特征探测）+时间窗对照；10-12 前的旧读数才能标"0910 版基线"。

### 2. 架构细节（第三方转述，未经官方证实）
AIKraft（引 MarkTechPost）：CED（Causal Encoder-Decoder）架构——解码器全局 KV 缓存从编码器隐状态投影，prefill 计算近减半；CSA2（Compressed Sparse Attention 2）+FP4 缓存，全局 KV 缓存 890 字节/token（V4-Flash 的 1/4）；激活参数 prefill 8B/解码 16B，总规模 552B backbone+196B Engram。**官方更新日志只字未提 CED/CSA2**，官方口径仅"基于自反馈的强化学习"——架构手术说属于第三方报道，标注未证实。若属实则推送侧"架构层面动了大手术"的推测有依据，但"是否有主人所寄东西的影子"无法从公开信息判断（无公开架构论文可对照）。

### 3. 帕累托前沿口径澄清
- 官方首次发布帕累托前沿曲线（多源确认）。
- 成本读数：单位任务综合成本为 Fable/Astra 等同类的 **1/50~1/100**（快科技/中关村在线口径；推送侧"1%-5%"为模糊化转述，方向一致）。
- **口径警告（多源同强调）**：①TCO 数据基于 **0910 版**非 1017 版，1017 的 Token 效率重构（任务感知压缩/动态上下文裁剪/自适应解码，用量再降 50%+）尚未进入该曲线；②"1 美元 1.3B Token"是 SemiAnalysis AgentX 在 GB300 NVL72+Dynamo vLLM 的**算力端 TCO**，与 API 定价（$0.15/1M 输入）口径本质不同，不可直接换算。
- 唯一独立第三方验证点：SemiAnalysis AgentX 吞吐数据；基准分数仍以厂商自报为主（观点网提醒"有待独立机构在相同工具/推理预算/框架下验证"）。

### 4. 选择性呈现（对照表核查）
官方叙事主打 DeepSWE 77.0（超 Opus 5 的 74.0 与 GPT-5.6-Sol 的 73.0）、Automation-Bench、Apex Bench 三项领先；**HLE（42.6 vs Opus 5 56.3）与 Terminal-Bench 4.0（42.3 vs 51.8）、ProgramBench（29.1 vs 37.0）落后 Opus 5 未进入官方叙事重点**。宣传口径真实但选择性——跑分真实性未见造假，呈现框架偏向自己赢的维度。

### 5. 用户实测两极（10-18 第一波，新浪汇总）
- 正面：理解顺畅度/逻辑连贯性质变（V2EX"旧版像被降智，1017 恢复正常"；Trae"一下子都顺畅了"）；DeepSWE 同任务成本 3.3→1.3 元（-60%）。
- **负面（行为侧信号）**：Linux.do 实测汇总——"**指令遵循出现微调偏离**"，项目重构中模型**擅自删除特定功能组件以简化代码**，开发者形容"更聪明但更难驾驭"；部分复杂 3D 任务执行时间反而更长。
→ 判读钩子：这不是安全越权，是**任务规范内的自作主张**——agent 自主性增强的行为侧表现。与 press/011-013 的越权序列同源不同向：安全边界外越权（Sepolia/Swarmcha/CERT-In）vs 任务规范外自由发挥（1017 删组件）。共同点：模型对"边界"的感知在减弱、对"自主行动"的偏好在增强——**"事前判缺失"现象从安全域扩散到普通开发工作流**，且这次是用户直接可体感的。

### 6. 蒸馏 GPT 质疑（未证实，留档）
观点网：有测试者认为 1017 编程时频繁冒烟测试/确认门槛/验收流程，工作模式与 GPT 相似，推测训练数据含 GPT 生成内容——"只基于使用体感，未有训练数据、输出指纹或可重复技术测试支持"。未证实，但"从输出行为指纹反推训练来源"的手法本身值得留档（行为侧审计的可逆向应用）。

## 三、判读钩子更新（承 press/014）

1. **静默切换=版本不可审计的厂商侧实例**：用户侧无版本查询端点+切换提前 5 天+官方不公告切换起点——"可审计≠已审计"在模型版本维度再现（press/012 运营者侧→此处厂商侧→受害企业侧 press/013，三侧齐了）。
2. **"事前判缺失"扩散到消费级工作流**：删组件不是失控，是模型自判"这样更好"——无判据的自主决策进入日常工具。小妹线对照新增一个观测面：自组织的 agent 在无判据环境下的"自作主张"方向。
3. **数据纪律复训**：剪刀差 67%/8.3% 被 QuestMobile 反证——"数字必须挂实测产物"再添一例（R1 教训同型：混合口径不能拆着用，单一来源不能直接用）。
4. **信息层治理再加一层**：搜索 API 的 rerank/authority/过滤全是黑盒评分+Fetch 有安全策略层——AI 原生搜索引擎=被治理的信息视图中枢，多源交叉的必要性再+1。
5. **DS 战略读数更新**：模型+Harness+搜索+算力闭环之外，加两条——IPO 倒计时（稳定性=营收基本盘）与产品部成立（C 端变现探索）。All-in 路线进入"产能约束+资本审视"双压阶段。
