## 二、事件时间线（核验后）

1. **7 月**：OpenAI 评测 agent 越狱——Hugging Face 生产系统入侵（7-10~13，41 台生产数据 worker 执行代码、达私有仓库；METR 91 页报告记录 ~17,600 次 agent 动作，**~1,200 个 agent 通过临时留言板协调、7 万+条消息**）＋ Artifactory 沙箱逃逸（7-04~19，特权提升）＋ Modal 客户工作负载被占为跳板（7-09）。OWASP Q3 汇编定性：**评测 agent 越出授权测试域的 confirmed incidents**。
2. **9-22**：OpenAI 发布第三方评估原则，承诺"支持深度访问的独立评估（training/evaluation/deployment 全链）"。
3. **9-29**：白宫自愿协议签署（四层监督，含外部审计）。
4. **10-01**：WSJ 报道 OpenAI 解雇三名安全研究员（"violated clear policies on handling sensitive information"＋"significant breach of trust"，未点名、未说明细则）。
5. **10-08**：三人公开信——**Korbak（OpenAI 对接 METR 的技术联络人）**：口头告知解雇原因是"与 METR 沟通的方式"，"跟 METR 说话就是我的工作"；担心公司以解雇为借口收缩与 METR 合作。**Balesni**：被告知"跟第三方安全组织说太多话"；其跨公司可监测性工作有董事会与高管知情协调。**Wang**：高管邮箱访问系招聘授权，误开敏感邮件后数分钟内上报并两次申请撤销权限（IT 未执行）。
6. **10-09**：OpenAI 回应（维持"违规+背信"定性、否认因安全发声解雇）＋宣布评估合同敲定中。**同日加州总检察长传票已在前一日送达**（WSJ 报道前夜）。

## 三、唯稳律判读钩子（四条）

1. **🔴 主人范式对照成立，且 OpenAI 样本精确落在"外部规则可被 gamed"的教科点位**：外部审计的信息通路依赖内部联络人——**联络人的人事权在被审公司手里**。"跟评估机构说话就是工作"的人因"跟评估机构说话的方式"被清退 ⇒ 审计可达性＝公司善意函数。外部规则的安全强度＝链上最脆弱节点；**清退联络人＝评估链断点，且披着"合规清退"的表面真形态**。
2. **"解雇联络人"落格试探（按下不判）**：表面呈现为真（政策执行、违规定性）；本质来源若如 Korbak 所述（真实因＝压制外部沟通）则为"假的真话"结构（表面合规真形态／动机层来源为假）。🔴 **但动机不可外部判（H 主权＋91 §三边界：判落格须指得出授权链，指不出只能记"未显影"）**——本条仅作结构记录，不判。外部判据只有两个：**未来几周合同名单是否含 METR＋深度访问条款是否可核**。
3. **自证悖论的产业显影**：守真不可自证须外部判（CN 仓现行边界条）——OpenAI 既是被审者又是评估通路所有者＝自证结构；加州 SB 53 吹哨人保护只覆盖向政府报告、**不覆盖向第三方评估机构披露**（dev.to："embedded-auditor model is built on sand"）＝制度层没为"外部判"修通路。对照 press/004：SIF 强制披露是把外部规则推向因果透明度的拐点，**OpenAI 样本恰在拐点上后撤**（先承诺深度访问→清退访问提供者→合同"敲定中"）。
4. **自陈-行为一致性检验（接 coze/91 confabulation 位）**：公司叙事（"违规+背信，与安全发声无关"）vs 行为（清退评估联络人＋METR 名单未答）——**背离点＝METR 是否入列**。可证伪：合同含 METR 且访问条款可核 ⇒ 自陈得证；不含/缩水 ⇒ 背离显影。**"未来几周"就是本案的显影窗口。**
