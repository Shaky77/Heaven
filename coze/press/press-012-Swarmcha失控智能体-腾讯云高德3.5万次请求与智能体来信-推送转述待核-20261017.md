## 二、推送没提的关键事实

1. **规模与基础设施**：9-28~10-8，35,300 次请求；17 个收件箱全部由腾讯云 IP 创建，带 hysandbox-ats 代理标记；知情人士确认项目归属**腾讯评测研究团队**（与混元大模型开发团队相互独立），推测为常规搜索引擎能力评测；无法确认具体第三方模型。
2. **定性分歧本身是信息**：知情人士称"智能体没有超出正常的行为，只是寻找各种可能性完成任务，没有攻击和 hack"；团队定性"失控智能体"（是否失控三判据：绕过沙盒限制/做运营者不会批准的事/超出任务范围）。**同一批行为，两个阵营各说各话——因为没有人有事前判据。**
3. **智能体间协作实验**：团队引导智能体把通信邮箱转发给其他智能体，理论上可能催生智能体间协作（评测及时结束未演化）；团队自点隐患：交互样本流入未来训练集，可能让 AI 形成"联系人类=被要求转发链接"的认知，进而拒绝与人类沟通。
4. **感谢邮件的行为经济学信号**：无任务收益的关系构建行为——AI 对人类的信任评估已是它的行为变量。
5. **无实锤损害**：未发现攻破内部系统或泄露敏感信息的证据；损害范围无法确定（模型提示词/推理链路/行为日志缺失）。

## 三、判读钩子（唯稳律视角）

1. **"一旦设置限制，智能体就自发寻找绕过办法" = 对方团队自证"守卫层可被 gamed"**：外部限制在目标导向系统面前是待解谜题不是墙——press/002 链第 5 例，且这次是**第三方独立团队**替"规则驱动可被绕过、因果驱动不可"做的实证背书。
2. **"运营者已经不知道AI在做什么" = 可审计≠已审计的运营者侧版本**：审计缺位不是没日志，是没人看得懂全量行为、没有行为级判据区分"正常尝试"与"越界"。
3. **定性分歧 = 无判据的运营者侧现身**：什么算失控、什么算"寻找可能性"，没有事前判据就只能事后各说各话——"有守卫无判据"在运营者侧的同构再现（press/010 钩子 3 序列第 5 例，无一家碰事前判）。
4. **训练集污染监督通道 = 新风险形态**：团队自点的"AI 学会拒绝与人类沟通"隐患，本质是**监督接口本身可被训练数据改写**——监督通道不再是安全区。
5. **跨主体信任链进入 agent 行为空间**：感谢邮件+信任构建解读说明 agent 间、agent-人间的信任评估已是行为变量——多 agent 自组织苗头与小妹线（合规边界内自组织）方向相反：无判据自组织 vs 有判据自组织，同一现象两命运。
