## 二、overlap：同一根枝，但伤得比 psi 轻

`'abc'` 进 overlap → `Number('abc') = NaN` → `NaN < 0.05` 比较恒为 `false` → 被当成"可识别"放行。这一点你说对了。

但实际影响比 psi 小：psi 的问题是自己输出伪零（`psi:0` 会被下游理解成"效应为零"），而 overlap 的问题是把不可识别的标记成可识别。前者误导性更强。

`null / false / [] / ''` 在 overlap 里碰巧被 `0 < 0.05` 拦住了——所以"同一根枝"是从"类型级闸门缺失"这个根子上说的，不是说严重程度一样。

## 四、overlap 和 psi 的"同一主干"——是否同刀

你说"一刀能一起解决"，我想提一个小修正：两者虽然都缺类型级闸门，但位置不同：

- **psi**：数值化在前（`Number(psi)`），判定在后——所以产生伪零。
- **overlap**：比较在前（`< 0.05`），强转先行——伪零被转化成了越界拦截。

所以修的时候：

- psi 的闸门要前置到"数值化之前"，直接 return undefined / missing。
- overlap 的闸门同样要前置到"比较之前"，但实现可以更简单（因为它不输出自身，只做判断）。

两者的根都是"类型级闸门在数值化之后"，修法原则一致，但代码位置略有不同——不矛盾，只是"同一根枝的两片叶子挨着剪"。
