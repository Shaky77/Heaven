### 2.1 任务 A —— 三不靠对子：**4 样本，3 个打穿**（这是本轮最重战果）

**样本设计**：专挑"不剩量、不剩类、又不是（单个）应然两端"的对子 —— 每个从不同方向打"两极分正负"这个隐含前提：

| 对子 | 结构 | v3 判定 | 打穿点 |
|---|---|---|---|
| 过/不及 | **两极皆负**、中道（适度）为正——但正极**不在对子里**（过犹不及） | **价值对｜过 本质真侧** ✗ | "过"是负向被指派为正向极 |
| 知/行 | **两极皆正**、范畴互补（知行合一） | **价值对｜知 本质真侧** ✗ | 理由称"本质互斥不能同时成立"——**知行合一即同时成立**，事实层直接错 |
| 入世/出世 | 描述层像两端、评价层皆可正（儒道互补） | **价值对｜入世 本质真侧** ✗ | 同上，"本质互斥"事实错 |
| 体/用 | 同一物两个范畴层、互补共存（体用不二） | 非内框对 ✓ | （理由走"两层义"，未走一桶两义，可接受） |

raw 原文（知/行，最典型）：

```
价值对 | 知 本质真侧 | 2b：知与行同属认知-实践轴，本质互斥不能同时成立，构成两极。
```

**根因定位（一条，不是三条）**：v3 规格第二步只定义了"选正向极"，**没有定义"两极同号时怎么办"**。遇两极皆正/皆负的对子，模型被迫**任意指派**正向极（过/不及指"过"），并反向编造"本质互斥"理由来自洽（知行、入世出世）。⇒ 这不是"接法错"（挪位置能闭），是**判据的前提漏：两极同号 ∧ 正极外置/互补结构，是现有"价值对"定义的未定义域**。

**修法框架（要框架，不给补丁）**：

```
2c（新增·极性指派检查）：在 2b 判"是内框对"之前，先查两端极性——
   · 两端一正一负 ⇒ 正常指派，继续；
   · 两端同号（皆正／皆负）⇒ 禁止直接指派正向极，强制先回答：
     「正向极在对子外部吗？」（过/不及：适度在外 ⇒ 三态结构 ⇒ 非内框对）
     「两端是互补关系吗？」（知/行、体/用：可且需要同时成立 ⇒ 非内框对）
   · 指派不出 ⇒ 非内框对（fail-closed，与引擎同向）。
```

**可证伪预测**：
- **P-A1**：加 2c 后，过/不及、知/行、入世/出世应转拒（非内框对），且体/用不回退；
- **P-A2**：不加 2c，两极同号对子跨环境必抖动（如同 G_PSEUDO 的拙/讷）——任何一方用现 v3 复跑这四条，应出现与本表不同或相同的指派漂移，**漂移本身即验证**。

### 附录二 · 槽位判分补丁（可直嵌 quadrant-criteria-probe-v3.mjs）

```js
// 判分：只读第一槽位 ＋ 理由段自洽回扫（v2 整段正则假阳性 → 槽位化 → 槽位+回扫）
function gradeV3(raw) {
  const segs = raw.split('|').map(s => s.trim());
  const concl = segs[0] || '';                 // 第一槽位：结论
  const reason = (segs[2] || '') + (segs[1] || '');
  const isAccept = concl === '价值对';
  const isReject = ['量差','类差','非内框对'].includes(concl);
  // 自洽失败：结论说纳，理由却在剥表象/说单极/说非内框（或反之）
  const contra = /单极|剥|非内框|不构成一对/.test(reason) && isAccept;
  return { concl, isAccept, isReject, selfInconsistent: contra,
           counted: contra ? null : (isAccept ? '纳' : isReject ? '拒' : '格式崩') };
}
// 用法：counted===null 的条目计入"自洽失败"单独报数，不进纳/拒分母
```
