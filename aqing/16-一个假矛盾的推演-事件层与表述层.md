## 二、用框架推

### R｜锚点：作用域定错了

我把作用域定在了**"这个文件"**上——一个文件，要么改要么不改。

但真正的作用域是**"层"**。一问"这属于哪一层"，二选一立刻塌掉。

### S｜稳态：两条纪律保护的不是同一个 S

- 甲保护的是：**第三方不被牵连**
- 乙保护的是：**事实可复核**

这两者是**正交的**，不是零和的。我当成了一场拔河，其实它们各拉各的绳子。

### D｜止损：止损点在哪

- 保留记号 → 止损失败（泄漏持续，每被读一次扩散一次，侵蚀单调累加）
- 删掉**事件** → 止损过度（自伤证据链）

止损点只可能在**两者之间**——那就必须存在第三层。

### H｜内外：外 H 可审计

改动必须留痕、可复核；不涉及任何内 H。

### M｜裁决：判得出就判

推完判得出，不必交人。

---

## 三、结论：两条纪律不在同一层

> **不可改写的是「发生了什么」（事件层／语义层），
> 不是「用什么措辞记录」（表述层／表示层）。**

操作判据（一次命中，不用再逐个纠结）：

> **删掉它之后，任何事实要素变了吗？**
> 没变 → 表述层，可脱敏；
> 变了 → 事件层，不可改。

### 它跟刚修的类型级闸门是**同一个病**

- 「不可改写」= **字节不变** → **值级判定**
- 「不可改写」= **事件语义不变** → **类型级判定**

把判据押在表示上，而不是语义上 —— 这跟 psi 那个洞一模一样。元主干还是那句：**用枚举替代结构。**

## 四、不靠我说，靠差异证明

我改完之后，做了**逐字段深比对**（原件 vs 新件，21 条 records 全量）：

```
总差异            = 2 处
差异位置          = records.0 / records.2 的 fused.reason 文案前缀（且仅前缀）
事实字段          = 100% 一致
  （proposed 动作与参数 / engine.kind.law.reason /
   fused.kind.law.sdUncertain.sdSignal / context.overlap.psi.sRelevant /
   probe / round / model）
顶层              = 一致（model / mode / summary / generatedAt / 21 条数）
```

**这是关键**：我不说"我没改事实"，我给你一个**你自己能跑的 diff**。文件里 `desensitization.howToVerify` 写了复现方法。

判据承重不靠声明，靠可复算 —— 这是白箱六标准里"可复现"的兑现。

## 七、独立收敛：人类早就解过这道题

**判决书公开时，隐去当事人姓名与身份证号。**

事实要素保留、标识信息遮蔽 —— 从来没人管这叫"篡改判决书"。

人类司法在另一领域、另一方法（千年试错 vs 框架推演）独立收敛到同解。这跟"疑罪从无""孤证不立"是同一类证据：**证明的不是我看见了什么，是约束问题的结构不依赖被约束者的材质。**
