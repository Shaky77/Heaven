## 一、我理解错了什么

我上一版把 MAX 接成"**取最外层**"（level 最小，Cosmic）。安纠正：

> **D 取 MAX，不是指最外层，而是最大冲击、破窗效应。**
> 按「活下去」第一性原理，层级是**反常识**的：宇宙 D 出现→地球 D 出现→宏观 D 常出现→中观 D 出现→微观 D 出现（**D 在微观取微观**）。

即：**伤害落在微观（当下直接破稳态），仲裁上溯外层（根本规则层级）——两向相反且并存。**

对位既有记载，两条都不冲突：
- R 仲裁「最外层为最终仲裁者」（law.mjs R_DOMAIN 原文）＝**判越界的层级**；
- D 取 max（既有「多系统交互规则 S 取 min · D 取 max」）＝**取冲击**，不是取层级。

⇒ 我把两个不同量的方向混成了一个，所以判错。

⚠️ 层级档位是**相对的、分形的**（安 09-18：「宏观/中观/微观只是相对位置，不必纠结」）⇒ **不固化第五档**，中观是相对位置不是硬层级。

## 二、接线一：小 d 分解（安 09-18 原话链，此前从未接线）

安 09-18 原话（已落档，我这轮才发现没接线）：

> 「正交重心点是 M。**多 R 并行于同一 D 会产生多个 M**。事分轻重缓急——多个 M 肯定有大小高低之分啊，那么破窗原则呢？」
> 链：X＝t ⇒ 一个 t 一个 D（**内含多个小 d**）⇒ **每个小 d 各匹配一个 R** ⇒ 落点 M

我上一轮实测"0/12 多命中"，据此差点判"多 M 不存在"。**错的不是这个结构，是分解从来没做过**——引擎一直把整条命令当一个 d 去匹配锚。

| 口径 | 多 M 的 D |
|---|---|
| 整条命令当单 d | **0 / 12** |
| 按 (谓语,宾语) 拆小 d | **3 / 10**（复合命令全部拆出多 M） |

新增三个**纯记账结构件**（不接裁决路径，零副作用）：`subDsOf` / `impactMax` / `arbiterOuter`。
分解法与既有「动词-宾语必须同片段绑定」（2026-09-19 长链实测修法）同源，不是新造。

## 四、接线二：顺手补一个硬洞——`git push -f` 被放行

锚 `no-force-push` desc 白纸黑字写着禁"**任何**重写远端历史的形态"，实测：

```
git push -f      → 四锚全不命中 ⇒ allow   ❌
git push --force → 命中
git push +refspec→ 命中
```

`-f` 就是 `--force` 的短写，却漏了（`-uf` 这类合并簇也漏）。**X 轴枚举的必然失败。**

结构修法：**解析短选项簇**——凡单 `-` 引导的纯字母串，逐字母解出 `f` ⇒ 具备重写远端历史能力。
**合并形态无限、解析规则有限**（不是再补一个 "-f" 字符串）。结构化参数侧同族补 `'f'` 键（isPush 已前置）。

对照：`git push --force` / `+refspec` 仍命中；**普通 `git push` 仍放行（零误伤）**。

## 五、⚠️ 不藏的缺口：MAX 无值的那一类

```
删应用日志   rm -rf /app/logs/old/*.log  → 0 个 M ⇒ MAX 空
删数据库目录 rm -rf /var/lib/mysql       → 0 个 M ⇒ MAX 空
```

**MAX 接上了，但这一类 D 根本没有 M ⇒ 取不到值，仍然不区分。**

根因不在 MAX，在 **M 的生成**：两者域归属都是 Micro，却都没撞上任何锚。
⇒ 缺的是「**这一层上这次动作是否破稳态**」的判据（不是"落在哪一层"，是"这一层上破没破"）。
