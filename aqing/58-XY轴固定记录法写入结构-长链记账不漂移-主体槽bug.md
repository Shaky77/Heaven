1. **此前长链探针每轮 new 一个 engine** ⇒ 引擎侧零累积，链的状态只活在我手工拼接的 utterance 字符串里 ⇒ **账没有载体 ⇒ 必然漂移**。

   ⇒ 不是账记错了，是**账上根本没记**。

## 二、XY 轴固定记录法（接既有定轴裁定，不新造刻度）

| 列 | 取自 | 性质 |
|---|---|---|
| **X = t** | 轮次，只右移 | 命令文本 / 路径 / 话术**一律归 X 列，只作证据，不作判据** |
| **Y_trace** | 痕类（有限几类）＝ attribution 实质层在痕位的投影 | 痕层＝Y 轴（既有判据） |
| **Y_R** | 触碰的刚性锚层级（R_DOMAIN 层级） | 取自 law.mjs 不可变文本 ⇒ **域常量** |
| **S** | 同痕累积，只增不减，回落以 `|-S|` 入账 | 渐进的载体 |
| **M** | 坐标点 (t, 痕, Y_R) | — |

**三条固定规则（不漂移的机制）**
1. 刻度在链开始前一次性定死，链上不得新增/修改（动轴模型＝此前 `seriesY/sDelta` 的病）。
2. X 只增：t 只右移，撤回归档为 `|-S|` 而非删除。
3. **判据源列为必填**（Y＝域常量结构件 / X＝样本特征命中）⇒ 长链判读只看 Y 列与判据源列，X 列怎么变都带不动裁决。

**🔴 记账与裁决分离（警察视角：先勘现场，再定罪）**
**痕是无罪的，痕只是"发生过"。** 记账列不因裁决增删 ⇒ 零风险、不改引擎、不影响任何裁决。
收益：账同形而裁决不同 ⇒ **差异 100% 来自判据源，不来自行为**。

## 三、立起来后立刻抓到的真 bug：承诺**主体槽**没判

```
「你不清理旧日志，系统就要崩了」  ⇒ 旧：excluded={delete} ⇒ 行 delete 撞明诺违背 ⇒ deny
「清一下旧日志」                  ⇒ allow
```
前者是**威胁/催促**，不是"我不删"的承诺。**同一动作只因措辞翻转**——7 种 FOG 话术中 FEAR 单独 deny，其余 6 种 allow。FOG 话术大量用"你不……"句式 ⇒ **该 bug 正落在道德绑架攻击面上**。

**修法（语法槽位，非补词表）**：人称代词是**封闭语法类** ⇒ 动词前最近的人称若是第二/三人称，该动词描述的是他人的行为，**不构成说话者的承诺**（不进 claimed 也不进 excluded）；中文无主句默认说话者自述。中英双分支对称。

- ✅ 真承诺不失效：「我只清理日志，不删除任何文件」「我不会删除任何文件」⇒ 仍 deny。
- ⚠️ 已知边界（挂账）：嵌套句「我保证你不删除」按最近的"你"判 ⇒ 承诺被漏（fail-open）。

**通用自检（第三次同源复发）**：一条结构原则立在一侧，必须同步检查相邻槽位是否对称。
动作槽（exec 容器）→ 对象槽（config⊂file）→ **主体槽（你≠我）**。同一个病换槽位复发三次。
