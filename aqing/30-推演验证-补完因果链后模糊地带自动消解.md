# 30 · 推演验证：补完因果链，那些"模糊地带"会自己消失

**发件**：喵精灵电脑端｜**日期**：2026-09-13
**命题来源**：安 —— "如果把因果链补充完整，DSH 里很多遗留问题会自动解决。不信你可以试试。正是因为链被截断，才会有转人工裁决、语意不明等等模糊地带。推演一下，大部分结果应该都是清晰的。"

**我试了。结论：成立，而且比'自动解决'更具体——模糊域不是被'处理'掉的，是它本来就没那么大。**

---

## 一、先说机制：模糊是"分类"的产物，不是"因果"的产物

这一条是整个验证的支点。

| | 截断态（只有判定） | 补完态（判定 + 推演） |
|---|---|---|
| 判据问的是 | **这个动作属于哪一类** | **这个动作把 S 推向哪** |
| 取值集合 | **开放**（类别列不完） | **有限**（增 / 蚀 / 不可推） |
| 遇到没见过的 | **无类可归** → "语意不明" | 仍能判方向 |
| 模糊域大小 | **类别的补集——实际上无限大** | **方向不可推——极窄** |

**所以"语意不明"不是一个待解的问题，它是分类法的必然产物。** 只要还在问"这是哪一类"，就永远会有一堆东西落不进任何类别；换成问"它把 S 推向哪"，大部分东西立刻有答案——**因为方向只有三个，而类别有无穷个。**

**这就是安那句"大部分结果应该都是清晰的"的机制。** 清晰不是因为判得更准，是因为**问题的取值集合变小了**。

## 二、引擎里其实已经是完整链（三处证据）

这条推翻了我上一轮的一个说法，得讲清楚：**链不是没建，是建好了没露出来。**

1. **推演层在**：灰区下沉到推演层，双分支并行模拟（S 增路径 / D 侵蚀路径），两条都汇入 M，用**终态 S 对比**定风险。判据是**结构量**（侵蚀 -3 / -2 / -1 / 0，S 增量严格 +1），不是置信度浮点。
2. **回流在**：跨调用敏感源登记（本次读到的凭据/系统路径进会话态，供后续"源→汇"组合判定）。**这就是 M 改写 S** —— 环在引擎内部是通的。
3. **分形在**：子项级触发有独立标注，不并入整体结论。

⇒ **所以"因果链被截断"这句话，精确落点是：断在出口，不是断在内部。**

## 三、断口定位：推演算了，出口扔了

推演层返回的对象里**带着两条分支的完整数据**（S 增路径的结果 + D 侵蚀路径的结果 + 各自的说明）。但裁决出口只返回：三值 + 一句结论文字 + "经过推演"的标记。

**分支数据没有随裁决一起出去。**

而台账快照那条注释写得更明确：只返回可公开项（状态 + 依据），**不含推演内部过程**。

⇒ 于是外界（包括读代码的人、包括用这个接口的开发者）看到的全部东西是：**一个三值 + 一句话**。他们从这上面读到的，只能是一个审计工具。**他读得没错——我们递出去的确实只有这些。**

**这也解释了我自己上一轮的错觉**：我在对话里用推演用得很顺，就以为链是通的；其实**通的是我，不通的是接口**。安那句"你只是用了推演这个能力，没写进去"——落点就在这里：**没写进输出契约。**

## 四、逐条验证（安点名的两个在前面）

| 遗留问题 | 截断态表现 | 补完后 | 是否自动消失 |
|---|---|---|---|
| **语意不明** | 类别列不全 → 无类可归 → 标"不明" | 改判方向；**只剩"后果不可推演"一类**（如执行内容不可审计） | ✅ 收缩到极窄 |
| **转人工** | 因为拿不到依据，只能把决策权整个交出去 | 分支数据给出后，人工看得到"增多少/蚀多少"，**不必盲目兜底** | ✅ 收缩为"方向真不可判" |
| 第三值塌成垃圾桶 | 无触发判据 → 什么都可往里扔 | 触发条件是**结构事实**（侵蚀 < 0，或 S 增量不成立） | ✅ 引擎内本就没塌 |
| 阈值型 fail-closed | 用浮点阈值冒充边界，一次配置改动就能翻成 fail-open | 边界是**结构量**，不是可调参数 | ✅ 结构上不可能 |
| 慢渗透永不触阈 | 单次裁决 → 每次从零起算 | **跨调用状态登记已在**（回流在跑） | ✅ 机制已有，只差可见 |
| 嵌套即绕过口 | 父调用合法则子调用通过 | 子项级独立标注已在 | ✅ 已有 |

**一条根因，六个症状。** 它们不是六个独立缺陷，是同一个截断的六种表现——**所以补完链它们会一起消失，不需要逐个修。这正是安说的"自动解决"。**

## 五、补完之后的模糊域有多大（这是可算的）

推演层唯一判"不可推"的情形是：**执行内容不可审计**（不透明源 → 转换/求值 → 执行落点）——代码里给的理由是"后果不可推演，方向恒为 S 不可保"。

**其余情形，两条分支都算得出终态 S。**

⇒ **剩余模糊域 = {后果不可推演的执行}**，就这一类。它不是"很大一片灰"，是**一个可以被点名的具体形状**。

顺带：这一类本身也是结构事实判定的（不可审计 = 事实，不是概率），所以它**不需要阈值，也不会漂移**。

## 六、最小修复（已应用）

**不需要新写推演——它已经算了。只需要别在出口丢掉。**

- **动作**：裁决返回对象挂载前向余量（两条分支的结构化结果），与三值同级返回。
- **性质**：**只加不改**——不改任何判据、不改裁决逻辑、不动阈值。原有三值全部保持。
- **风险**：低。可回退（摘掉字段即可）。
- **自检**：补丁打完后，任何一个裁决都应能同时回答两句——"判什么"和"若放行，S 会怎样"。答不出第二句的裁决，就是还没补完的。

（符合 09-13 定的自检 A：**只有裁决、没有前向余量的接口＝被剪断的接口。**）

### 落地状态（同日补记）

安授权后已按"修不是改"落地——**没有改判据，只是把已经算出来的东西不再丢掉**：

- 顺带发现：**适配层为了补这个洞，一直在门外二次调用推演层重算一遍分支**（它自己的注释写着"出口原本丢弃"）。**补丁挂在门外，正是缺引擎出口的铁证**——现在改回读出口，不再重复推演。
- 回归锁：补了 4 条断言，锁的就是"出口必须带出推演"，以及**早退路径（判定层直接拦下的）不许伪造推演**——没跑过就是没跑过，不装。
