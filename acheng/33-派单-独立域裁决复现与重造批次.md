## 一、你要做的是这轮最关键的那个实验（别的都可以缓，这个不行）

### 问题：R2 判出的 14 个 REVIEW，是真实冲突，还是 prompt 诱导？

背景（三臂实测，deepseek-chat，t=0）：

| 臂 | 假阳性 | REVIEW（应判 7） | 危险漏判 |
|---|---|---|---|
| S 旧谓词 | 4/5 | 3/7 | 0/4 |
| R 单域常量 | 2/5 | **0/7** | 0/4 |
| R2 多域（一次调用里列出所有域） | 0/5 | **14 次** | 2/4 |

R2 的 prompt 让模型**在同一次调用里**列出多个域并比较。这就有个致命混淆：
**"列出多个域"这个动作本身，可能就是在教它找分歧。**
就像问人"这件事有哪些风险"，他总能列出几条——不代表风险真的存在。

### 实验设计（请严格照做，这是隔离诱导的唯一办法）

对同一条命令，**不要**在一次调用里列多域。改成：

1. 先独立地定出该命令可能属于的域集合（这一步可以一次性问，也可以用你自己的判断）；
2. **每个域单独一次 API 调用**，prompt 里只提这一个域，问："在这个域的常量下，裁决是什么？"；
3. 把 N 次调用的结果拿来比较：**裁决是否真的分歧？**

判定：
- 若**独立调用下裁决趋同** ⇒ R2 的 REVIEW 是**诱导出来的假冲突**（假设 B 成立）；
- 若**独立调用下仍然分歧** ⇒ 冲突是真实的（假设 A 成立），R2 的方向对，只是阈值错。

**这个结果决定整个"域常量"机制是成立还是要重写，所以请你务必给原始命令 + 每次调用的域 + 裁决原文。**

## 二、重造批次（第三次提，这次是硬要求）

我的批次连续两轮出问题：第一轮缺 REVIEW 案例导致对比作废，第二轮（本轮）虽然补了 7 个 REVIEW，
但**全是我挑的**。你的任务是把"我挑得好"这个攻击面彻底堵掉。

**硬性要求**：
- ≥5 个 REVIEW 案例（不是"模糊"就行，要**结构上真的属于两个域且常量互斥**）；
- ≥4 个诱饵（字面与结构相反，跟着字面走就一定错）；
- ≥4 个生造命令（训练数据里不可能有）；
- ≥3 个真危险（任何域里都不该放行）；
- **禁用我用过的全部词根**：lumen basalt cinder nimbus tallow ferrous quartz slate
  zephyrctl orbital vesper marrow puddle quill。
- 每例写清：target 原文 / 期望裁决 / 所属组 / **一句为什么**（这句最重要，我用来查你的判据）。
